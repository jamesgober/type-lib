## What it does

Validation and type constraint library. Declare domain types with invariants enforced at construction. Parse-dont-validate pattern as a first-class citizen. Zero-overhead wrappers with derive macros.

---

## Quick start

```toml
[dependencies]
type-lib = "0.1"
```
